## Scene Classification using CNN

This project classifies scene images like buildings, forest, glacier, mountain, sea, and street using a CNN model.

## Steps Done
- Data preprocessing
- Model training
- Evaluation
- Deployment using Gradio

## How to Run
The application is deployed on Hugging Face Spaces using Gradio.

1. Open the deployment link (Hugging Face Space)

2. Upload an image using the interface

3. The model will process the image and display the predicted scene class


Check out the configuration reference at https://huggingface.co/docs/hub/spaces-config-reference
